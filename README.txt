Wordsearch Workshop
-------------------
index.html   The whole app in one file. Open it in a browser, or upload it to any web host.
source/      The separate source files. Run `sh build.sh` inside it to rebuild index.html and test.html.

Everything runs in the browser. Puzzles and settings are saved in that browser only.
The AI tab uses your own Gemini API key, kept in the browser and sent only to Google.
