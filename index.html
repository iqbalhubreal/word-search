Wordsearch Workshop ZIP Builder

This builder retrieves the repository file objects by their saved Git blob IDs, applies the requested fixes, and downloads a ZIP containing index.html plus the complete source/ folder and original supporting files.

Included updates: clearer editable text fields, adjustable grid-letter size, word-bank row/column controls, individual puzzle titles, per-page layout editing with an “Apply to all” checkbox, and bulk generation with a save confirmation.

Ready. Internet access is needed to retrieve the saved file objects from GitHub.

The original GitHub repository is not modified. This creates a separate local ZIP file.
